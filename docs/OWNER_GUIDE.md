# คู่มือเจ้าของ — NORX Website (หนึ่งหน้า)

**เปิดงาน:** เปิดโปรเจกต์เดิมใน Claude Code หรือ Codex แล้วพิมพ์ “ต่อ” เพื่อดูรายงานไม่เกิน 5 บรรทัด หรือสั่งงานที่ต้องการโดยตรง ถ้าโฟลเดอร์เก่า/งานชน AI จะเตือนและหยุดเขียนก่อนแก้ปัญหา

**ทำงาน:** สั่งทีละเป้าหมาย เช่น “ทำหน้าแก้ภาพปกหน้าแรก” AI จัดการตรวจข้อมูล เลือกเครื่องมือ แบ่งงานเมื่อจำเป็น ทดสอบและบันทึกให้อยู่ในขอบเขตเดียวกัน ไม่ต้องส่งข้อความไปมาระหว่าง AI เอง

**ติดลิมิต/เปลี่ยนเครื่อง:** ใช้ GitHub เป็นที่เก็บงานจริง ก่อนสลับต้องมี checkpoint ที่ push สำเร็จ และปล่อยผู้เขียนแล้ว เปิดอีกตัวจาก repo ที่ซิงค์แล้วและพิมพ์ “ต่อ” ถ้า push ไม่ได้ ให้ AI แจ้งว่ามีงานค้างอยู่บนเครื่องนั้น ไม่เขียนทับงานเดิม ไม่บังคับ merge

**จบงาน:** AI บันทึก GitHub, อัปเดต STATE และ [การ์ด Trello สถานะ](https://trello.com/c/a89Pbdgg) สั้น ๆ ให้เห็น “ผู้เขียน / กำลังทำ / เสร็จล่าสุด / ถัดไป / รออนุมัติ” ไม่ต้องเปิดหลายหน้าต่าง

**สิ่งที่ยังต้องอนุมัติ:** Cloudflare ทุกการเขียน (deploy/migration/D1/DNS/route/Access/Email), Production/V1/Events/Media, เรื่องเงิน/QR/ข้อมูลลูกค้า ตามขอบเขต `CLAUDE.md`. งานปกติที่สั่งและอนุมัติแล้วทำต่อได้ ไม่ต้องถามซ้ำ. ไม่ซื้อเครดิต ติดตั้งเครื่องมือ หรือเปลี่ยนระบบจริงโดยพลการ

ถ้าไม่แน่ใจให้ดูการ์ด Trello เพียงที่เดียว; หลักฐานเทคนิคอยู่ GitHub. กฎ AI ทั้งหมดอยู่ `CLAUDE.md` — คู่มือนี้ไม่ใช่กฎชุดที่สอง.
