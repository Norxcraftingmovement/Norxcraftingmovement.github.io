# คู่มือเจ้าของ 1 หน้า — เปิดงาน ทำงาน จบงาน

คู่มือนี้สำหรับเจ้าของเท่านั้น (ไม่ต้องอ่านโค้ด) กฎของ AI อยู่ใน `CLAUDE.md` ที่เดียว ที่นี่บอกแค่ว่า "คุณต้องทำอะไร"

## 1. เริ่ม (ทุกครั้ง)
1. เปิดแอป กด **New** ในโปรเจกต์ `Norxcraftingmovement.github.io` (โฟลเดอร์ `work/norx-dashboard` โฟลเดอร์เดียว ไม่ต้องเลือกโฟลเดอร์อื่น)
2. พิมพ์ว่า **ต่อ**
3. คำตอบแรกต้องเป็น **รายงานสถานะไม่เกิน 5 บรรทัด** (สาขา/commit, ตรงกับ GitHub ไหม, ทำอะไรแล้ว, ขั้นต่อไป, รออนุมัติอะไร)
4. ถ้าบรรทัดแรกเตือนว่า **"โฟลเดอร์เก่า"** หรือบอกว่า **ไม่พบ AGENTS.md / CLAUDE.md / STATE.md** → หยุด อย่าสั่งงาน ปิดเซสชันแล้วเรียกผมหรือเซสชันใหม่มาแก้โฟลเดอร์ก่อน
5. ถ้ามันไม่รายงานสถานะเอง พิมพ์ว่า **ทำตาม AGENTS.md** อีกครั้ง

## 2. ระหว่างทำงาน
- สั่ง **ทีละงาน** ประโยคเดียวพอ เช่น "ทำหน้าแก้ไขสินค้า"
- งานหนึ่งชิ้น = หนึ่งเซสชัน = หนึ่งสาขา = หนึ่ง PR อย่าสั่งหลายเรื่องรวมกัน
- อย่ากดปุ่ม **Create PR** ที่แผงด้านขวาเอง ให้ AI เปิด PR ให้ถูกสาขา (ต้องเข้า `feature/orders-v2`)
- เซสชันที่ยาวมาก (บริบทเกินราว 200K) ให้จบแล้วเปิดใหม่ AI ควรเตือนเอง ถ้าไม่เตือนให้ถามว่า "ควรเปิดเซสชันใหม่ไหม"

## 3. จบงาน
1. พิมพ์ว่า **จบงาน**
2. AI ต้อง: push สาขา, เขียน `STATE.md` ทับ, คอมเมนต์สั้น ๆ ที่การ์ด Trello สถานะ
3. ตรวจที่การ์ด Trello สถานะ (`trello.com/c/a89Pbdgg`): บรรทัดบนสุดต้องเขียนว่า **ผู้เขียน: ไม่มี**

## 4. ติดลิมิต / สลับเครื่องมือหรือเครื่อง
- เปิดเครื่องมืออีกตัว (เช่น GPT/Codex) **ในโฟลเดอร์เดิม** แล้วพิมพ์ **ต่อ** ไม่ต้องคัดลอกแชตมา
- ก่อนสลับ ตรวจที่การ์ดว่าใครเป็น **ผู้เขียน** ถ้ายังมีชื่อ ให้ตัวเดิมจบงานหรือปล่อยก่อน (ต้องมีผู้เขียนคนเดียวเสมอ)
- ถ้าตัวใหม่รายงานว่างานไม่ตรงกับที่คุณจำ ให้เชื่อ GitHub และสาขาก่อนเชื่อแชตเก่า

## 5. แบ่งเลนงาน (กันงานซ้ำ)
| เลน | ตัวอย่าง |
|---|---|
| Orders | ออเดอร์ รอบ การผลิต จัดส่ง การชำระ ซ้อมย้าย V1 |
| Products / เนื้อหาเว็บ | สินค้า ธีม หน้าสินค้า หน้าแรก |
| เอกสาร / ขั้นตอน | `CLAUDE.md`, `STATE.md`, คู่มือนี้ |

แต่ละเลนมีผู้เขียนได้คนเดียวในเวลาเดียว (ใครจะเขียน ให้เขียนชื่อไว้ที่ "ผู้เขียน" บนการ์ดก่อน)

## 6. เรื่องที่ต้องเป็น "คุณพิมพ์ว่าอนุมัติ" เสมอ
เขียน Cloudflare ทุกอย่าง (deploy, migration, D1, route, DNS, Access, Email), แตะ production / V1 / Events / Media, และเรื่องเงิน/QR/ข้อมูลลูกค้า AI ต้องถามเป็นรายการ ๆ ไม่ใช่อนุมัติครั้งเดียวทั้งหมด (รายละเอียดใน `CLAUDE.md`)

## 7. อาการ → ทำอะไร
| อาการ | ทำอะไร |
|---|---|
| บอก "ไม่พบไฟล์" / "โฟลเดอร์เก่า" | หยุด แก้โฟลเดอร์ก่อน (ข้อ 1.4) |
| push ไม่ผ่าน HTTP 403 | บัญชี GitHub ผิด ล็อกอินใหม่: `git credential-manager github login --username Norxcraftingmovement --browser` แล้วให้ AI ลองใหม่ |
| งานของสองเครื่องมือไม่ตรงกัน | ดูที่ GitHub (สาขาและ PR) เป็นหลัก แล้วบอก AI ให้รวมตามนั้น ห้ามบังคับ rebase เอง |
| AI ทำเรื่องที่ไม่ได้สั่ง | พิมพ์ "หยุด" แล้วให้รายงานสถานะ |
| ไม่แน่ใจว่างานถึงไหน | อ่านการ์ด Trello สถานะที่เดียว (บรรทัดบนสุด) |
